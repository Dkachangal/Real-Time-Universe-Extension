# 🌌 Real-Time 3D Planetarium Chrome Extension & mobile AR Controller

A custom browser extension that transforms your standard "New Tab" page into a live, interactive 3D planetarium, controlled entirely by your smartphone. Built to bridge the gap between digital workspaces and the night sky, this project renders ~9,000 celestial bodies at their precise, real-time coordinates.

## ✨ Features

* **Immersive 3D Starfield:** Replaces the default new tab with an interactive 3D universe using React Three Fiber.
* **Mobile AR Telemetry:** A companion React Native app captures live GPS and IMU sensor data, acting as a physical window into the digital sky.
* **Real-Time Synchronization:** A custom Node.js/Socket.io WebSocket pipeline streams smooth, 360° telemetry across devices at 60 FPS.
* **Astronomical Accuracy:** Parses the HYG Database to render the ~9,000 naked-eye visible stars out of 120K+ objects.
* **Custom Shaders:** Utilizes shader materials to dynamically map actual astronomical temperatures to accurate visual star colors.
* **Hardware Noise Reduction:** Implements a Low-Pass Filter and angle-unwrapping logic on the mobile client to process raw IMU data, preventing jitter and gimbal lock.
* **Live Orbital Computation:** Computes orbital equations on the fly for real-time planetary trajectories.

## 🛠️ Architecture & Tech Stack

**Chrome Extension (Client):**
* React.js
* React Three Fiber / Three.js
* Custom WebGL Shaders

**Mobile Controller (AR Client):**
* React Native
* Expo Sensors (Gyroscope, IMU, GPS)

**Backend (Telemetry Sync):**
* Node.js
* Socket.io (WebSockets)

## 🚀 Installation & Setup

### 1. Backend Server Setup
1. Clone the repository and navigate to the server directory.
2. Install dependencies: `npm install`
3. Start the WebSocket server: `npm start`
4. *Note the local IP address or deployment URL for the client connections.*

### 2. Chrome Extension Setup
1. Navigate to the `extension` directory and run `npm install`, then `npm run build`.
2. Open Google Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the `build` (or `dist`) folder generated by the extension project.

### 3. Mobile AR Controller Setup
1. Navigate to the `mobile-app` directory.
2. Install dependencies: `npm install`
3. Update the WebSocket connection URL in the app to point to your running Node.js server.
4. Run the app on your physical device using Expo: `npx expo start` (A physical device is required for IMU/GPS sensor hardware).

## 🧠 How It Works

1. The **Mobile App** continuously reads IMU and GPS data.
2. The data is passed through a **Low-Pass Filter** to smooth out hardware noise and prevent erratic camera jumps.
3. The cleaned telemetry is streamed instantly to the **Node.js Server** via Socket.io.
4. The **Chrome Extension** listens for these socket events and translates the orientation vectors into the Three.js camera rotation.
5. Meanwhile, the extension calculates the current date/time to align the parsed HYG database coordinates, rendering the exact sky you would see if you looked up.
